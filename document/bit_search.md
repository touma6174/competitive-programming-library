## 1. bit全探索とは

「$N$ 個の要素それぞれに対して『選ぶ / 選ばない』の $2$ 通りの選択肢があるとき、全 $2^N$ 通りの組み合わせをすべて調べるアルゴリズム」です。

- **主な用途**: 集合の部分集合の全列挙、スイッチの ON/OFF 組み合わせ判定、条件を満たす最適値の探索
- **計算量**: $O(2^N \times N)$
- **適用限界**: $N \le 20$ 程度（$2^{20} \approx 10^6$）まで。

---

## 2. 基本原理とビット演算子

$2$ 状態の組み合わせを $N$ 桁の 2 進数に対応させて管理します。

| 演算 | 意味 | コード例 | 補足 |
|---|---|---|---|
| **左シフト** | $2^N$ の計算 | `1 << N` | 通り数を表す |
| **右シフト＋AND** | $i$ 番目のフラグ判定 | `(bit >> i) & 1` | $i$ 番目が $1$（選ばれている）か判定 |

---

## 3. 具体的な動作

| 動作 | Python | C++ |
|---|---|---|
| $i$番目の要素が選ばれているか | `(bit >> i) & 1` | `(bit >> i) & 1` |
| $i$番目の要素を追加する | `bit \| (1 << i)` | `bit \| (1 << i)` |
| $i$番目の要素を削除する | `bit & ~(1 << i)` | `bit & ~(1 << i)` |
| 選んだ要素の個数を数える | `bit.bit_count()` | `__builtin_popcount(bit)` |

## 4. 基本テンプレート (C++ / Python)

### C++17
```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int N = 3;
    vector<int> A = {10, 20, 30};

    // 2^N 通りを全探索 (1 << N は 2^N と同等)
    for (int bit = 0; bit < (1 << N); ++bit) {
        int sum = 0;
        vector<int> selected;

        for (int i = 0; i < N; ++i) {
            // bit の i 番目の立っている（1 である）かを判定
            if ((bit >> i) & 1) {
                sum += A[i];
                selected.push_back(A[i]);
            }
        }

        // ここで組合せごとの処理（判定・出力など）を行う
    }
    return 0;
}
```

### Python 3
```python
N = 3
A = [10, 20, 30]

# 2^N 通りを全探索
for bit in range(1 << N):
    sum_val = 0
    selected = []

    for i in range(N):
        # bit の i 番目が立っている（1 である）かを判定
        if (bit >> i) & 1:
            sum_val += A[i]
            selected.append(A[i])

    # ここで組合せごとの処理（判定・出力など）を行う
```

## 5. 応用パターンと代表例題

### 1. 部分和問題 (Subset Sum)
- **問題**: 要素数 $N$ の配列 $A$ からいくつか選んで、和をちょうど $K$ にできるか？
- **ポイント**: 各組み合わせの合計値を求め、`sum_val == K` になるか判定する。

### 2. ポップカウント (`popcount`) の利用
- 選んだ要素の個数に制限がある場合（例: 「ちょうど $K$ 個選ぶ」など）、立ったビットの数を数える関数を使用すると効率的です。
  - C++: `__builtin_popcount(bit)`
  - Python: `bin(bit).count('1')` または `bit.bit_count()` (Python 3.10以降)

## 6. 注意点と計算量目安

- **オーバーフロー注意 (C++)**: $N \ge 30$ の場合は `1 << N` が 32bit 数の上限を超えるため、`1LL << N`（`long long` 型）を使用する必要があります（※ただし $N \ge 30$ の場合は計算量的にTLEとなるため、半分全列挙などの別解法を検討してください）。
- **$N$ の値による計算量見積もり**:
  - $N = 10 \implies 2^{10} = 1,024$ （一瞬）
  - $N = 20 \implies 2^{20} \approx 10^6$ （十分間に合う）
  - $N = 30 \implies 2^{30} \approx 10^9$ （**TLE**）
