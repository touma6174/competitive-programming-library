## 1. ビット演算の基礎と主要演算子

各桁（ビット）ごとに独立して論理演算を行う操作です。

| 演算子 | 名称 | 概要・規則 | 例 (2進数) |
|---|---|---|---|
| **`&`** | **AND (論理積)** | 両方が $1$ のとき $1$ | `5 & 3` (`101 & 011`) $\rightarrow$ `001` ($1$) |
| **`\|`** | **OR (論理和)** | 少なくとも一方が $1$ のとき $1$ | `5 \| 3` (`101 \| 011`) $\rightarrow$ `111` ($7$) |
| **`^`** | **XOR (排他的論理和)** | 互いに異なるとき（一方が $1$ でもう一方が $0$） $1$ | `5 ^ 3` (`101 ^ 011`) $\rightarrow$ `110` ($6$) |
| **`~`** | **NOT (反転)** | $0$ と $1$ を反転する | `~5` (`~101`) $\rightarrow$ `...11111010` (補数表現) |
| **`<<`** | **左シフト** | 全ビットを左にずらす（$2$ 倍） | `1 << 3` $\rightarrow$ `1000` ($8$) |
| **`>>`** | **右シフト** | 全ビットを右にずらす（$1/2$ 倍・切り捨て） | `6 >> 1` (`110 >> 1`) $\rightarrow$ `011` ($3$) |

## 2. XOR (排他的論理和) の性質と性質活用

XOR（記号 $\oplus$）はAtCoderで極めて頻出の演算です。以下の主要な性質を押さえておくことが重要です。

### 1. XORの基本性質
- **自己消滅 (Involution)**: $a \oplus a = 0$ （同じ値を2回XORすると0になる）
- **単位元**: $a \oplus 0 = a$
- **交換法則**: $a \oplus b = b \oplus a$
- **結合法則**: $(a \oplus b) \oplus c = a \oplus (b \oplus c)$
- **逆元が存在する**: $a \oplus x = b \iff x = a \oplus b$

### 2. XORの応用テクニック
- **桁ごとの独立性 (Bitwise Independence)**:
  各ビット桁は他の桁の繰り上がり・繰り下がり等の影響を受けないため、**桁ごとに独立して計算（数え上げ）できる**。
- **累積XOR (Prefix XOR)**:
  配列 $A$ の区間 $[l, r)$ のXOR和は、累積XOR配列 $R_i = A_0 \oplus A_1 \oplus \dots \oplus A_{i-1}$ を用意することで、$R_r \oplus R_l$ の **$O(1)$** で求められます。

## 3. ビット演算の代表テクニック・関数

### 1. フラグ操作
- **$i$ 番目のビットを立たせる（1にする）**: `a | (1 << i)`
- **$i$ 番目のビットを降ろす（0にする）**: `a & ~(1 << i)`
- **$i$ 番目のビットを反転させる**: `a ^ (1 << i)`
- **$i$ 番目のビットが立っているか判定**: `(a >> i) & 1`

### 2. 立っているビット数のカウント (Popcount)
- C++17: `__builtin_popcount(x)` (64bitは `__builtin_popcountll(x)`) / C++20: `std::popcount(x)`
- Python: `x.bit_count()`

### 3. 最下位ビットの抽出 (Lowest Set Bit)
- **コード**: `x & -x`
- **概要**: 2の補数の性質を利用して、$x$ の中で最も右にある（最下位の）$1$ だけを残した値を抽出します（Indexed Tree / BITなどで利用）。

## 4. 応用パターンと問題例

### パターン1: 桁ごとに独立して考える (桁ごとの数え上げ)
- **問題**: 配列 $A_1, A_2, \dots, A_N$ のすべてのペア $(i, j)$ に対する $A_i \oplus A_j$ の総和を求めよ。
- **解法**:
  全体の計算を各ビット $k$ ($0 \le k < 60$) に分解します。
  $k$ 桁目が $1$ である要素数を $c_1$、$0$ である要素数を $c_0$ とすると、その桁の寄与は $(c_1 \times c_0) \times 2^k$ となり、これを全桁足し合わせることで $O(N \log (\max A))$ で解けます。

### パターン2: 2回現れる要素の特定（または奇数回現れる要素）
- **問題**: 配列の中で1つの要素だけが奇数回現れ、それ以外のすべての要素は偶数回現れる。奇数回の要素を特定せよ。
- **解法**: 配列全体をそのままXOR和をとると、偶数回現れる要素は $a \oplus a = 0$ で相殺され、奇数回現れた要素だけが残ります。

## 5. まとめと注意点

- **演算子の優先順位に注意**:
  C++等ではビット演算子（`&`, `|`, `^`）の優先順位が比較演算子（`==`, `!=`）や加減算（`+`, `-`）より**低い**ため、必ずカッコ `()` で囲む必要があります。
  - 誤: `if (a & 1 == 0)` $\rightarrow$ `if (a & (1 == 0))` と評価される
  - 正: `if ((a & 1) == 0)`
- **64bit整数のシフト操作 (C++)**:
  32bitを超えてシフトする場合、`1LL << i` のように型を指定しないとオーバーフローします。
