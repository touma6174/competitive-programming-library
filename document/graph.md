## 1. グラフの基本概念と表現方法



### グラフの表現

- **隣接リスト (Adjacency List)**: 競プロにおける標準的な表現。

- 重みなし: `vector<vector<int>> G(N);`

- 重み付き: `vector<vector<pair<int, long long>>> G(N);` (行き先, コスト)

- **隣接行列 (Adjacency Matrix)**: 頂点数 $N \le 1000$ 程度で、辺の有無を $O(1)$ で判定したい場合に使用。



### 基本走査

- **幅優先探索 (BFS / Breadth-First Search)**:

- キュー (`std::queue`) を使用。

- **重みなしグラフの単一始点最短経路**を $O(V + E)$ で計算。

- グリッド（迷路）上の最小手数問題などの定石。

- **深さ優先探索 (DFS / Depth-First Search)**:

- 再帰関数またはスタック (`std::stack`) を使用。

- 連結成分のカウント、サイクル検出、木構造の巡回・トポロジカルソートに利用。

## 2. 最短経路アルゴリズム



| アルゴリズム | 対象・条件 | 計算量 | 主な用途・特徴 |
|---|---|---|---|
| **0-1 BFS** | 辺の重みが $0$ または $1$ | $O(V + E)$ | `std::deque` を使用。重み $0$ は `push_front`、重み $1$ は `push_back` |
| **ダイクストラ法** | 負の辺がない重み付きグラフ | $O(E \log V)$ | **最頻出**。優先度付きキュー (`priority_queue`) を使用 |
| **ベルマン・フォード法** | 負の辺を含むグラフ | $O(VE)$ | 負の閉路（ネガティブサイクル）の検出に使用 |
| **ワーシャル・フロイド法** | 全点対間最短経路 | $O(V^3)$ | $V \le 300$ 程度の小規模グラフで全ペアの最短距離を一括計算 |

## 3. 木（Tree）の性質とアルゴリズム



木とは「閉路を持たない連結無向グラフ」であり、頂点数 $N$ に対して辺の数は常に $N - 1$ 本です。



### 重要な性質とテクニック

1. **木の直径**:

    - 木の中で最も離れた2頂点間の距離。

    - **求め方**: 任意の頂点 $u$ から最も遠い頂点 $X$ を BFS/DFS で探し、次に $X$ から最も遠い頂点 $Y$ を探す。 $X-Y$ 間の距離が直径となる ($O(N)$)。

2. **最小共通祖先 (LCA / Lowest Common Ancestor)**:

    - 2頂点 $u, v$ の共通の祖先の中で最も深い頂点。

    - ダブリングを用いることで、前計算 $O(N log N)$、クエリ $O(log N)$ で取得可能。

    - 頂点 $u, v$ 間の距離: $dist(u, v) = depth(u) + depth(v) - 2 depth(LCA(u, v))$

3. **木DP (木上の動的計画法)**:

    - 葉（末端）から親に向かって順に計算結果を合成・伝播させる DP。

4. **全方位木DP (Rerooting)**:

    - すべての頂点を根とした場合の答えを $O(N)$ で一括計算する高度テクニック。

## 4. 二部グラフと奇閉路の同値性



### 定理

> **「グラフが二部グラフであること」 $\iff$ 「グラフ内に奇閉路（頂点数が奇数のサイクル）が存在しないこと」**



### なぜ成り立つか？

1. 二部グラフは頂点を「黒」と「白」の2色で交互に塗り分けられるグラフです。

2. 閉路をたどる際、1歩進むごとに色は反転します。

3. 偶数長の閉路では元の色に戻りますが、**奇数長の閉路では到達時に逆の色になり矛盾**が生じます。



### 判定方法 ($O(V + E)$)

- **2色塗り分け (BFS / DFS)**: 隣接する頂点に異なる色を割り当てていき、既に塗られている頂点と矛盾（同じ色）が生じれば奇閉路が存在。

- **拡張 Union-Find**: 各頂点 $u$ に対して「表 $u$」「裏 $u + N$」を用意し、辺 $(u, v)$ に対し $(u, v+N)$ と $(u+N, v)$ を結合。 $u$ と $u+N$ が同一グループになれば奇閉路が存在。

## 5. グラフの連結性と特殊な閉路



1. **強連結成分分解 (SCC / Strongly Connected Components)**:

    - 有向グラフにおいて「互いに行き来可能」な頂点グループに分解。

    - 分解後のグループを縮約すると **DAG (有向非巡回グラフ)** になり、トポロジカルソート順に処理が可能。

2. **関節点（Cut Vertex）と 橋（Bridge）**:

    - 関節点: 取り除くとグラフが不連結になる頂点。

    - 橋: 取り除くとグラフが不連結になる辺。 LowLink アルゴリズムで $O(V + E)$ で検出。

3. **オイラー閉路 (Eulerian Path / Circuit)**:

    - すべての**辺**をちょうど1回ずつ通る経路。

    - **無向グラフの存在条件**: グラフが連結かつ、奇数次数（繋がっている辺が奇数本）の頂点が **0個（閉路）** または **2個（小道）**。

4. **ハミルトン閉路 (Hamiltonian Path)**:

    - すべての**頂点**をちょうど1回ずつ通る経路（NP困難）。

    - $N \le 20$ 程度であれば **bitDP** を用いて $O(2^N N^2)$ で計算可能。

## 6. ネットワークフローと最小カット



### 基本概念

- **最大流問題**: 送出側 (Source) から受取側 (Sink) に最大でどれだけの流量を流せるか。

- **最小カット問題**: Source と Sink を分断するために取り除くべき辺の容量の総和の最小値。

- **最大流最小カット定理**: **（最大流量）＝（最小カットの容量和）**



### 燃やす埋める問題 (Project Selection Problem)

- 「要素 $A$ を選ぶとコスト」「要素 $B$ と $C$ を同時に選ぶとペナルティ」といった二項関係の最適化問題を最小カットに帰着して解く定石パターン。

## 7. 競プロで差がつくモデル化テクニック



1. **拡張グラフ (拡張ダイクストラ / 状態付きBFS)**:

    - 単に「頂点 $v$」だけでなく「（チケット残り枚数・現在の状態など）$s$ における頂点 $v$」として、状態を含めた頂点 $(v, s)$ 上で探索を行う。

2. **超頂点 (Super Node / Virtual Node)**:

    - スタート地点やゴール地点が複数ある場合、架空の1頂点をつくり、そこから各スタート地点へ重み $0$ の辺を張ることで単一始点問題に帰着。

3. **補グラフの BFS**:

    - 元のグラフの「辺がない部分」に辺が存在する補グラフでの最速探索。未訪問頂点の集合（`std::set` など）を保持し、高速にスキップ処理を行う。

4. **ダブリング (Doubling)**:

    - 各頂点から「 $2^k$ 歩進んだ先の頂点」を前計算 ($O(N log K)$)。 $K$ が非常に大きい場合の移動後の位置や LCA の高速取得に適用。

## 8. AtCoder Library (ACL) の活用



AtCoderのC++環境では `#include <atcoder/all>` を指定することで利用可能です。



- `atcoder::dsu`: Union-Find構造体。連結判定や要素の統合をほぼ定数時間で実行。

- `atcoder::scc_graph`: 強連結成分分解を $O(V + E)$ で実行。

- `atcoder::maxflow`: Dinic法による最大流・最小カットを計算。

- `atcoder::mincostflow`: 最小費用流問題を解く。

- `atcoder::twosat`: 2-SAT問題を有向グラフのSCCに帰着して解く。

- `atcoder::segtree` / `atcoder::lazysegtree`: セグメント木 / 遅延セグメント木による区間クエリ高速化。
